## 仍然存在的科学限制

19,634 个站点小时运营状态未证实，审计 panel 未补成确认营业。档案计数模式中的零只表示无保留记录，不是零潜在需求。真实历史库存与容量未知；时间边界的历史在途记录也取决于可用档案。调运瞬时、半径、容量、预算、距离成本及受阻归还行为都是假设。

时长阈值 180 分钟已配置和测试边界；更长阈值的完整重新清洗敏感性未运行。站点位置来自训练期压缩摘要和近似矩形，非经验证的行政区/迁移数据。季节 lag 跨 DST 是经过的 168 小时，不总是相同本地钟点。真实在线部署数据可用性需单独验证。

这些限制不能通过重复模拟或 bootstrap 消除。参见 reports/项目总结.md 和 outputs/official。当前网络阻塞已解除，旧网络诊断为历史记录；无需上传全年 ZIP。已按新增清单要求提交并推送 GitHub main，未独立验证新任务快照恢复。

新清单：英文 8 页 PDF、命名站点的高峰解读、额外两张 EDA 图、GBFS 实采和 GitHub 可见结果小表已补齐。测试以最新 pytest.txt 为准。
